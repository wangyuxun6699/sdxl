# V11 开场城市：球面空间与街区层次

本版在 v10 上迭代，保留紫黑哑光材质、缓慢自转、贴地紫色波纹、逐栋响应和静态颗粒。以下说明对应本版；V8–V10 文档仅作历史记录。

## 使用

将 ZIP 中 `frontend` 里的文件覆盖到原项目的 `frontend` 目录，保留本机 `node_modules` 与 `.env`，执行 `npm run dev`。本版没有增加依赖；`package.json` 仅增加 `test:intro` 脚本。

按钮文字改为“进入规划工作台”。它仍直接进入现有业务页面，没有新增账户认证流程。简介缩短为“以扩散模型生成城市规划方案，联动空间形态与环境分析。”

## 可见变化

- 加入条形低层建筑、带裙房的塔楼、少量围合街区，与普通体块共同形成主、次中心层次。
- 地块先避让主次道路，再安排建筑占地，避免较大建筑跨越道路。
- 所有建筑共用球面坐标与相机投影。每栋建筑以统一的局部基础平面生成屋顶和立面，裙房与塔楼也共享基础平面，消除自转时固定屏幕菱形屋顶的错位感。
- 屋顶、立面与各建筑部分按相机深度排序，并对背面剔除。远处透明度平滑消退，固定地球轮廓线进一步压低。
- 加入轻微接地暗影，保留暗部靛蓝反光；使用更细的调色板，让受波后的亮度变化连续。
- 模拟景深采用整幅场景的低分辨率图像与连续透明度遮罩合成，扩大中景清晰区域，减少模型沙盘感。它是轻量的屏幕空间近似，不是三维深度缓冲驱动的光学景深。
- 扩大窄屏地球投影，补充矮屏布局，避免横屏时按钮被截断。

## 扩散与交互

- 波纹在单位球面上生成，并先于建筑绘制，由建筑遮挡；不绘制波纹中心白点、地标圆点或浮在城市上方的整圈光环。
- 每栋建筑根据波前距离产生错峰起光、短暂抬升与余辉回落。合并响应平滑限幅，建筑高度增量最高限制为自身高度的 21%，日常响应随波纹强度衰减。
- 可见波纹名额在创建时为整个生命周期保留，不再按当前亮度交换显示对象。普通档最多同时显示 3 条、低性能档 2 条；其余有效波继续驱动建筑。
- 鼠标从最前面的可见屋顶或立面命中建筑；天空、空隙和按钮不使用“最近地面点”替代命中。
- 手机点触可触发局部扩散，离开页面时清理动画和监听器。切换系统减少动态效果偏好会立即生效，页面在该模式下保持完整静态城市。

## 绘制开销

- 星空、球体底色、远雾和中心补光缓存到背景画布，只在尺寸或画质改变时重建。
- 屋顶辉光在较小的画布上模糊，分隔帧更新；景深共用一张低分辨率场景图，减少整屏滤镜操作。
- 场景顶点和路径投影复用对象，文字区域尺寸只在尺寸变化时读取。
- 普通设备以 60 FPS、低性能设备以 30 FPS 为调度目标；保留帧时间余量，修复原有阈值跳帧问题。实际帧率取决于浏览器与设备，这不是帧率保证。
- 根据实测绘制耗时逐级减少像素分辨率与景深开销，必要时降到 30 FPS。额外限制画布像素预算，避免高分屏无效绘制。
- 页面隐藏时暂停并重置帧时钟，返回后不补算离开期间的动画。

## 验证

- `npm run build` 通过。入口脚本约 117 KB（gzip 约 45 KB）；Cesium 仍是独立异步模块。构建中较大模块提示来自 Cesium。
- `npm run test:intro` 通过：覆盖不同网格的道路与地块占用、多个旋转角度下的几何与面命中、60/120/144 Hz 刷新下的帧调度。
- 使用项目实际 Canvas 代码进行了桌面与窄屏离线绘制，检查静态、自动波、鼠标响应和减少动态效果画面；同时验证天空和按钮排除、触摸触发、后台暂停与销毁清理。
- 当前环境的浏览器无法访问本地页面，因此没有完整 DOM 页面截图或真实浏览器帧率数据。离线 Canvas 验证不能替代这些检查。
- `App.vue`、业务配置、共享样式、入口、Vite 配置与依赖锁文件均与 v10 按字节一致。

主要实现位于 `src/components/cityGeometry.js`、`cyberGlobeScene.js` 与 `CityIntro.vue`。
